# A lesson note

When you correct the AI, have it write the lesson down as a short note: one lesson per note, with
the reason. The next conversation reads the notes before it starts, so the same mistake is not
made twice.

## Template

```
<The lesson, in one line.>

Why: <what went wrong, or who asked for it, and why it matters>

How to apply: <what to do differently, as steps>
```

## Example

This is one of the notes from the talk, in the same words. A PR (pull request) is a proposed
change to a project, sent for review before it is added. Automatic checks run on it and report
whether it works.

```
A PR is not done until every check has passed.

Why: my user asked for this. A PR handed over with checks still running leaves the last check
to them.

How to apply: watch the checks to the end. If one fails, read the error, fix it, and watch again.
```
