# Ask for proof, not a report

Use this when the AI says it is done, or tells you a fact you are going to rely on. "Done" is a
report. What you want is something you can check: the file, the figure and where it came from,
the link, the check that passed.

```
Before I accept this as done, show me:

1. What you ran or checked to know it works, and the output it gave. If you did not run a check,
   say so plainly.
2. For each number you gave me: where it came from, and whether you looked it up or worked it
   out just now, or remembered it.
3. For each fact from outside this conversation: the link.
4. Anything you did not check.
```

Then try the result yourself once: open the file, follow the link, run the thing.
